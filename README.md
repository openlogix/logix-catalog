# Logix Catalog

Every FPGA board, described once.

**Coming Q4 2026.** This repository is a placeholder; the work hasn't started here yet. See the [Logix Catalog page](https://www.openlogix.org/catalog/) for what's planned.

Logix Catalog is the open catalog of FPGA boards behind every Logix tool: each board's FPGA, how to program it, and what its pins are wired to, one JSON file per board. Logix Engine builds it in, and other projects can use the data too. It's part of [Open Logix](https://www.openlogix.org/): free, open source tools for FPGA design that install in one step, run on macOS, Windows and Linux, and need no separate toolchain.
